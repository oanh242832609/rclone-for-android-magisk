# rclone-for-android-magisk

Модуль Magisk/KernelSU для монтирования облачных хранилищ на Android с помощью rclone.

## ✨ Возможности

- 🚀 **Автоматическая загрузка бета-версии**: Автоматически загружает последнюю бета-версию rclone при установке
- 🌐 **Поддержка KernelSU WebRoot**: Веб-интерфейс для настройки модуля для пользователей KernelSU
- 📦 **Поддержка нескольких архитектур**: Поддерживает arm64, arm-v7, x86_64 и x86
- ☁️ **Монтирование облачных хранилищ**: Подключение нескольких облачных провайдеров (Google Drive, Dropbox, OneDrive и др.)
- 🔄 **Автоматическая синхронизация**: Встроенный демон синхронизации для автоматической загрузки файлов
- 🎯 **Простая настройка**: Легкая конфигурация через терминал или веб-интерфейс

## 📋 Требования

- Android устройство с root доступом (Magisk или KernelSU)
- Интернет соединение при установке (для загрузки бинарного файла rclone)
- Аккаунт облачного хранилища (Google Drive, Dropbox, OneDrive и т.д.)

## 🔧 Установка

1. Скачайте последний релиз со страницы [Releases](https://github.com/oanh242832609/rclone-for-android-magisk/releases)
2. Установите модуль через Magisk Manager или KernelSU
3. Перезагрузите устройство
4. Настройте rclone через терминал: `rclonew config`
5. Или создайте файл конфигурации по пути `/sdcard/.rclone/rclone.conf`

## 🌐 Веб-интерфейс (KernelSU)

Если вы используете KernelSU, вы можете получить доступ к веб-интерфейсу конфигурации:

1. Откройте KernelSU Manager
2. Перейдите на страницу webroot модуля
3. Или откройте конфигурацию напрямую по пути `/data/adb/modules/com.piyushgarg.rclone/webroot/index.html`

## 📝 Настройка

### Быстрый старт

```bash
# Настройка облачных хранилищ
rclonew config

# Перемонтировать все настроенные хранилища
rclonew remount

# Проверить статус
rclonew

# Отмонтировать все хранилища
rclonew unmount
```

### Файл конфигурации

Создайте или отредактируйте файл `/sdcard/.rclone/rclone.conf` с учетными данными вашего облачного хранилища.

Пример конфигурации:
```ini
[gdrive]
type = drive
client_id = your_client_id
client_secret = your_client_secret
token = {"access_token":"..."}
```

### Расширенная настройка

Вы можете настроить параметры монтирования, создав файлы `.param`:

- Глобальные параметры: `/sdcard/.rclone/.global.param`
- Параметры для конкретного хранилища: `/sdcard/.rclone/.имя_хранилища.param`

Примеры параметров:
```bash
# Включить HTTP сервис
HTTP=1
HTTP_ADDR=127.0.0.1:38762

# Включить FTP сервис
FTP=1
FTP_ADDR=127.0.0.1:38763

# Привязать к SD карте
BINDSD=1

# Установить режим кэширования
CACHEMODE=writes
```

## 📂 Структура директорий

- `/mnt/cloud/` - Корневая точка монтирования для всех облачных хранилищ
- `/sdcard/Cloud/` - Точка монтирования доступная с SD карты
- `/sdcard/.rclone/` - Файлы конфигурации и логов
- `/data/rclone/cache/` - Директория кэша
- `/data/adb/modules/com.piyushgarg.rclone/webroot/` - Веб-интерфейс (KernelSU)

## 🔄 Автоматическая синхронизация

Модуль включает демон синхронизации, который может автоматически загружать файлы с вашего устройства в облачное хранилище.

Чтобы включить синхронизацию для хранилища, создайте файл параметров:
```bash
# /sdcard/.rclone/.имя_хранилища.param
SDSYNCDIRS=DCIM:Pictures:Documents
SYNC_WIFI=1
SYNC_CHARGE=0
SYNC_BATTLVL=20
```

## 🛠️ Решение проблем

### Модуль не работает после перезагрузки
- Проверьте существует ли файл `/sdcard/.rclone/rclone.conf`
- Проверьте логи в `/sdcard/.rclone/rclone.log`
- Попробуйте перемонтировать: `rclonew remount`

### Хранилища не монтируются
- Проверьте подключение к интернету
- Проверьте конфигурацию rclone: `rclone config`
- Посмотрите сообщения об ошибках в файле логов

### Установка не удается
- Убедитесь, что у вас есть подключение к интернету во время установки
- Проверьте, поддерживается ли ваша архитектура
- Попробуйте переустановить модуль
