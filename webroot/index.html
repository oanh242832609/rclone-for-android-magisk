Quick Start Guide

  • Create configuration file at: /sdcard/.rclone/rclone.conf
  • Or use the terminal command: rclonew config
  • Reboot or remount: rclonew remount
  • Check status: rclonew

📝 Terminal Commands

Available Commands

# Configure rclone remotes
rclonew config

# Remount all remotes
rclonew remount

# Unmount all remotes
rclonew unmount

# Disable a specific remote
rclonew disable <remote_name>

# Check rclone version
rclone version

🌐 Web Services

Enable Web Services

To enable HTTP/FTP/SFTP/DLNA services, edit your global parameters file:

# Create global parameters
vi /sdcard/.rclone/.global.param

# Example settings:
HTTP=1
HTTP_ADDR=127.0.0.1:38762
FTP=1
FTP_ADDR=127.0.0.1:38763
