📝 Terminal Commands

Available Commands

# Configure rclone remotes
rclonew config

# Remount all remotes
rclonew remount

# Unmount all remotes
rclonew unmount

# Disable a specific remote
rclonew disable <remote_name>

# Check rclone version
rclone version

🌐 Web Services

Enable Web Services

To enable HTTP/FTP/SFTP/DLNA services, edit your global parameters file:

# Create global parameters
vi /sdcard/.rclone/.global.param

# Example settings:
HTTP=1
HTTP_ADDR=127.0.0.1:38762
FTP=1
FTP_ADDR=127.0.0.1:38763

📝 Configuration Files

Main Configuration

Location: /sdcard/.rclone/rclone.conf

This is where you configure your cloud storage remotes.

Global Parameters

Location: /sdcard/.rclone/.global.param

Configure global settings like HTTP server, cache mode, etc.

Per-Remote Parameters

Location: /sdcard/.rclone/.<remote_name>.param

Configure settings for specific remotes.

💡 Tip: Use a file manager app or terminal text editor to edit these files.
